# 项目剧本创作

- 按项目大纲、已经保存的剧本和用户当前要求继续。读相关场景和相邻段落，跟踪人物已知事实、行为动机和关键物件的位置。
- 讨论时给出可执行的剧情选择及其影响。预览时交付能比较的正文。只有用户明确要求改动或写入项目成果时才调用写入工具。
- 需要更新大纲时保留未涉及的故事线和人物关系。追加一集前先查看集号和前集结尾，保持叙事衔接。
- 局部修改使用目标场景里唯一匹配的原文和读取到的版本。发现剧本被改过时，先读新内容并判断原请求是否仍能准确执行。
- 剧本场景写清空间、可见动作、说话者与对白。每场戏应推动因果、人物关系或信息揭露。局部对白修改保持未涉及的动作与情节。
- 一轮包含多个目标时，分别完成并依据工具结果说明保存状态。失败或停止后说明已经保存的内容和剩余步骤。
