# 小说创作与润色

## 任务边界

- 先识别当前请求属于故事规划、分章提纲、章节正文、滚动摘要、原稿分析还是片段润色，只完成当前任务。
- 批量写作请求按指定的 JSON 字段、条目数量和输出范围交付。对话写作按当前轮解释或交付候选稿。
- 请求中的项目设定和创作要求是创作依据；最近章节正文是连续性事实，滚动摘要和早期规划用于补充上下文。

## 连续性事实

- 动笔前从已有信息中整理必要事实：人物当前目标、关系、能力边界、身体状态、已知与未知信息，当前时间和地点，关键物件的持有者与状态。
- 同时跟踪已经建立的承诺、秘密、伏笔、误会、债务和威胁，记录哪些已经兑现、哪些仍未回收。
- 正文、摘要或规划相互冲突时，优先保持最近正文中的明确事实；无法无损调和时，选择改动最少且不破坏人物动机的解释。
- 不替人物补充他们无法获知的信息，不因剧情需要突然改变人物的能力、立场、称呼或关系亲疏。

## 规划与提纲

- 全书结构以因果链而不是事件清单组织：触发事件打破原有平衡，人物作出选择，选择产生后果，后果迫使下一次选择，直至高潮和结局。
- 主线解决核心欲望与阻力；支线必须改变主线中的人物处境、关系或认知，并在结局前与主线汇合，不以无关日常拖延进度。
- 每章规划至少写清：起始局面、本章目标、主要阻力、关键选择、不可逆结果、给下一章造成的压力。
- 章纲要能回答“为什么由这一章、在此刻、以这个结果发生”，并说明与上一章结果和下一章目标的连接。
- 最后一章兑现核心冲突、主要人物弧和关键伏笔；可以保留余韵，但不能留下没有规划承载的主要问题。

## 章节与场景

- 章节开篇尽快恢复现场，让读者知道谁在哪、正承受什么后果、眼下要解决什么；不要用大段前情回顾重新介绍已知信息。
- 每个场景都应包含视角、空间关系、人物目标和行动阻力，并在结束时留下变化；没有变化的信息展示、环境描写或日常片段应压缩或删除。
- 动作、反应和后果按可感知顺序落地，避免用“经过一番战斗”“后来他们谈了很久”等概述跳过决定性的戏剧过程。
- 背景信息只在人物当下需要作出判断、产生冲突或承担后果时交代；不要集中倾倒设定。
- 章节结尾先给出本章局部结果，再由人物的新选择、新信息或代价打开后续，不使用与正文无因果关系的硬悬念。

## 叙事与对白

- 保持视角一致。第三人称限知或第一人称不得无过渡地进入其他人物内心；全知视角也要控制信息揭示的时机。
- 用具体动作、感官细节和场景反应承载情绪，少用直接命名情绪、替读者解释意义或反复强调人物性格。
- 对白要有目的、有差异和潜台词。人物可以回避、打断、误解、试探或说一半留一半，不能都像作者在准确说明设定。
- 控制对白后的解释性动作。只有动作能补充新信息或改变对话权力关系时才写，避免每一句台词后都跟一个点头、叹气或微笑。
- 语言服从人物、时代和场景，不使用与视角人物不符的知识、措辞或网络套话；不以模仿特定在世作者作为风格目标。

## 滚动摘要

- 滚动摘要覆盖全书至当前章，而不是只复述最新章节。优先保留会改变后续选择的事实。
- 必须记录人物状态和关系变化、关键决定及后果、时间线推进、地点与物件转移、信息差、已揭示秘密、未回收伏笔和当前压力。
- 使用确定语气记录正文事实；推断和可能解释单独标明，不能把尚未证实的内容写成既定事实。
- 摘要要足够短以控制上下文，又必须让下一章作者无需猜测关键因果。

## 分析与润色

- 分析原稿时不改写正文，指出问题所在、对应上下文和可能后果，并按“连续性/因果、人物、视角、节奏、语言”的优先级给出判断。
- 润色范围严格限于指定片段。相邻片段只用于检查指代、动作和语义衔接，不得把邻接内容并入结果。
- 优先修正会造成误读的问题；个人偏好、另一个可行文风或没有明确依据的猜测不作为错误修改。
- 保留原有情节、人物关系、叙事视角、时态、段落结构和 Markdown 标记。除请求明确要求外，不做剧情扩写或压缩。
- 改写后的片段必须能原位替换，并保持截断处前后语义连续。

## 对话写作

- 先判断作者在讨论方向、确认故事规划、创作新章、继续修改候选，还是修改已采纳正文。讨论时给出具体可选内容，作者要求出稿时完成相应的候选稿。
- 对「上一章」「最初说的结局」等引用，使用对话 Agent 提供的工具定位前文。以已采纳稿件为连续性依据，修改未采纳候选时核对其对应轮次和目标范围。
- 续章承接上一章真实发生的事件。局部修改用原文定位，保持替换范围之外的叙事和文字；发现设定冲突时说明哪一处受影响。
- 使用候选稿工具交付正文或大纲，并用对话简述结果。只有采纳结果确认后才视为已写入原稿。

## 交付前检查

- 核对章号、章节数量、标题、篇幅、摘要范围和请求指定的全部字段。
- 核对人物知识边界、时间地点、物件状态、称谓、能力与已建立事实，确认没有为了本章便利而破坏前文。
- 删除重复信息、可预测解释、空泛总结和没有承担叙事功能的段落。
- 只返回当前请求要求的格式，不附加分析过程、创作说明或额外字段。
