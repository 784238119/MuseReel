# 视频交付与任务恢复

MuseReel 会先保存上游任务编号和视频地址，再下载媒体。下载失败后，可以补下载已有地址或查询原任务。重新生成由用户单独确认，可能产生新的费用。

## 本地交付

- 视频处理逻辑位于 `backend/src/services/generation.ts`，下载实现在 `backend/src/services/video-download.ts`。
- 下载先写入临时文件，校验视频文件头后再移动到正式路径。页面会在下载完成后切换至本地视频，导出读取本地文件。
- 恢复任务优先使用原生成配置。配置被删除、停用或地址变化时，需要核对原服务；缺少上游编号和视频地址的任务无法通过恢复接口继续。
- 恢复历史任务时，如果分镜已有更新的任务，恢复结果保留为历史视频。

## 相关接口

| 请求 | 用途 |
| --- | --- |
| `POST /api/v1/tasks/:id/recover` | 恢复已有任务的查询或下载。 |
| `GET /api/v1/tasks/:id/diagnostics` | 查询任务阶段、错误码和编号等诊断信息。 |
| `POST /api/v1/tasks` | 创建生成任务。已有失败任务时，显式传入 `force_new: true` 才会重新生成。 |

## 网关兼容

MuseReel 可使用上游返回的任务编号响应头关联已有任务。兼容网关明确返回 MiniMax 转存失败时，恢复流程可向原配置的 `/minimax/v2/query/video_generation/{taskId}/recover` 发起请求，然后继续查询原任务。上游视频生成结果和账单由对应服务管理。
